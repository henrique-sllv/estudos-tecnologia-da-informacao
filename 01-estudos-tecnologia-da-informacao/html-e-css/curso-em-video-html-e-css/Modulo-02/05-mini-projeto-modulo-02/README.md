# Sobre o Projeto

Este é o segundo miniprojeto de estudos desenvolvido com HTML5, CSS3 e VS Code. A página apresenta um artigo completo contando como surgiu o mascote do Android.

## 💡 O que você vai encontrar por aqui:
- **A origem do mascote:** A primeira versão criada por Dan Morrill (os *Dandroids*)
- **O surgimento do Bugdroid:** Como a ilustradora Irina Blok criou o visual definitivo inspirado nas placas de banheiro
- **Curiosidade extra:** A lista em ordem alfabética das versões do Android nomeadas com doces (do *Cupcake* ao *Pie*)
- **Estrutura completa de artigo:** Menu de navegação, conteúdo principal com imagens e vídeo incorporado, além de uma seção complementar (`<aside>`)
