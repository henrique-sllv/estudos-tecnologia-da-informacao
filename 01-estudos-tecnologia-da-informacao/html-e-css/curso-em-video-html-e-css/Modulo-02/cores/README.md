# 🎨 Cores

> Registro prático e evolução dos estudos sobre aplicação, psicologia e efeitos de cores na web.

---

## 🎯 O que foi praticado nesta etapa

- **Psicologia das cores:** Estudo de como as cores transmitem sensações, emoções e influenciam a experiência do usuário.
- **Paleta de cores:** Escolha e combinação harmoniosa de tons para dar identidade visual aos projetos.
- **Degradê:** Criação de transições suaves entre duas ou mais cores utilizando propriedades do CSS.

---

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estruturação e semântica)
- **CSS3** (Estilização)
- **Visual Studio Code** (Editor de código)
